# みもすそ川公園｜壇ノ浦と関門海峡を歩く

壇ノ浦古戦場、長州砲、関門トンネル人道を一つの旅として紹介する、日本語の観光ウェブサイトです。

## 開発

```sh
pnpm install
pnpm dev
```

本番用の確認と生成：

```sh
pnpm check
pnpm build
pnpm check:build
```

生成物は `dist/` に出力されます。静的サイトとして配信できます。

公開先のURLが決まったら、ビルド時に `PUBLIC_SITE_URL` を設定すると、各ページに正規URLと絶対形式の共有画像URLが出力されます。

```sh
PUBLIC_SITE_URL=https://example.jp pnpm build
```

## ページ

- `/` — 総合案内
- `/park-guide/` — 園内の見どころ
- `/history/` — 壇ノ浦と長州砲の歴史
- `/kanmon-tunnel/` — 関門トンネル人道
- `/itineraries/` — 時間別モデルコース
- `/access/` — 交通・駐車場
- `/food/` — 周辺の食事
- `/photo-spots/` — 撮影ガイドと写真出典
- `/faq/` — よくある質問

## 写真

主要な実景写真は、山口県観光連盟のフォトダウンロード利用規約に基づき、観光宣伝用途で使用しています。補助写真は、利用条件が明確なウィキメディア・コモンズの写真を使用しています。詳細は撮影ガイド内の「掲載写真の出典」にまとめています。

## 更新時の注意

バス、駐車場、紙芝居、長州砲の演出、関門トンネル人道、市場や店舗の案内は変更される場合があります。本文に時刻表や営業日を追加するときは、公式情報への導線を保ち、変わりやすい情報を断定しないようにしてください。
